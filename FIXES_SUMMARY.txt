WHAT WAS BROKEN
================================================================================

The Course Interest Dropdown in the New Enquiry Modal displayed with:
  ✗ Search icon overlapping input text
  ✗ Dropdown panel clipped by modal scroll container
  ✗ Dropdown items partially hidden
  ✗ Dropdown couldn't position properly
  ✗ Scrolling caused positioning issues
  ✗ Z-index fixes didn't work

ROOT CAUSE: CSS Stacking Context Constraint
─────────────────────────────────────────────
The modal body has `overflow-y: auto`, which creates a stacking context.
When a parent element has overflow, it constrains any positioned children.
Even `position: fixed` doesn't escape a parent's stacking context.

This is a CSS specification behavior, not a bug.
Solution: Use React Portal to render dropdown outside the modal DOM tree.

DEVELOPER NOTES
================================================================================

Why React Portal is the Right Solution:
  • Industry standard for dropdowns/modals/tooltips
  • Used by Material-UI, Ant Design, Chakra UI, Bootstrap
  • Completely escapes parent constraints
  • Maintains accessibility
  • Zero performance overhead
  • Recommended by React documentation

Why CSS-Only Solutions Didn't Work:
  • Stacking context can't be overridden with CSS
  • `position: fixed` doesn't escape parent stacking contexts
  • `z-index` only works within same stacking context
  • `clip-path` also creates stacking context
  • No CSS workaround for this architectural issue

This Fix vs. Competitors:
  • Better than z-index hacks (which don't work)
  • Cleaner than absolute positioning workarounds
  • More performant than custom scroll tracking
  • More maintainable than Shadow DOM
  • Standard industry practice
